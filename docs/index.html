Security & Installation Notice

Why does macOS or Windows flag newly downloaded open-source software?

Why am I seeing an "Unidentified Developer" or "Windows Protected Your PC" warning?

Re:triever is 100% free and open-source. Because we do not charge for subscriptions or pay commercial software vendor certificates ($300+/year), macOS Gatekeeper and Windows Defender SmartScreen display a default warning for new open-source downloads. This is a standard false positive.

🍎 Opening on macOS

  1. Control-Click (or Right-Click) Re:triever.app and select Open.
  2. Click Open on the prompt (or go to System Settings ➔ Privacy & Security ➔ Open Anyway).

🪟 Opening on Windows

  1. Double-click Re-triever-Setup-1.0.0.exe.
  2. Click More info on the blue SmartScreen screen.
  3. Click Run anyway.
